Import MJ (page sans la table de combat)

Page réservée au MJ pour les imports ponctuels. La table de combat n'y tourne pas : ses abonnements ne peuvent donc pas modifier les données pendant l'import.

  1. Connecte-toi avec le compte MJ (lien magique).
  2. Ouvre la console du navigateur (F12).
  3. Données de l'ancienne plateforme : tylImporterDonnees(), puis choisis export.json (et manifest.json).
  4. Contenus protégés et secrets du MJ : tylImporterProtege(), puis choisis mi.json, clp.json et/ou secrets-mj.json.

Revenir à la table de combat.
